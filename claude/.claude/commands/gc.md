# Git Commit and Push (Full Workflow)

Generate a commit message, get user approval, then commit and push in one flow.

## Instructions

1. **Run `/gm`** to generate and present a commit message
2. **Wait for user approval.** Do NOT proceed until the user confirms the message. If the user suggests changes, revise and ask again.
3. **Run `/gp`** with the approved commit message to commit, push, and create a PR if needed
